# Campus-Network-Lab


A hands-on enterprise campus network lab built with EVE-NG Community Edition and Cisco IOL devices. This project focuses on Layer 2 switching, Layer 3 routing, VLAN segmentation, EIGRP, and network troubleshooting.

Project Overview

This lab simulates a multi-layer enterprise campus network using Cisco IOL routers as distribution devices and Cisco IOL Layer 2 switches at the access layer.
